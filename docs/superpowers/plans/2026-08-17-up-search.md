# UPSearch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with checkpoints.

**Goal:** Build a SwiftUI `UPSearch` that mirrors the uview-plus `u-search` props, defaults, event payloads, and imperative focus/blur/clear surface without depending on the shared workspace's uncommitted files.

**Architecture:** Add a focused `UPSearch` component file containing the view, controller, normalization helpers, and event pipeline. Add a separate `UPSearchConfig.swift` extension for defaults so `UPConfig.swift` remains untouched. Use a `Binding<String>?` plus local `@State` fallback, `@FocusState` for native focus, and a controller that registers closures rather than exposing UIKit objects.

**Tech Stack:** Swift 6, SwiftUI, XCTest, Swift Package Manager, existing `UPConfig`, `UPStyle`, `UPUnit`, `UPIcon`, `UPColor`, and `UPTheme` primitives.

- [ ] **Step 3: Implement the main-actor controller with queued actions.**

```swift
@MainActor
public final class UPSearchController: ObservableObject {
    private var focusHandler: (() -> Void)?
    private var blurHandler: (() -> Void)?
    private var clearHandler: (() -> Void)?
    private var pending: [() -> Void] = []

    public init() {}

    public func focus() { dispatch { self.focusHandler?() } }
    public func blur() { dispatch { self.blurHandler?() } }
    public func clear() { dispatch { self.clearHandler?() } }

    func register(focus: @escaping () -> Void, blur: @escaping () -> Void, clear: @escaping () -> Void) {
        focusHandler = focus
        blurHandler = blur
        clearHandler = clear
        let pending = self.pending
        self.pending.removeAll()
        pending.forEach { $0() }
    }

    func unregister() {
        focusHandler = nil
        blurHandler = nil
        clearHandler = nil
    }

    private func dispatch(_ action: @escaping () -> Void) {
        if focusHandler != nil || blurHandler != nil || clearHandler != nil { action() }
        else { pending.append(action) }
    }
}
```

The actual implementation must dispatch each action against its corresponding handler rather than treating any registered handler as available; queued actions preserve call order.

- [ ] **Step 4: Implement normalized commit and external-value synchronization.**

```swift
static func commit(_ proposed: String,
                   binding: Binding<String>?,
                   maxlength: Int?,
                   onChange: ((String) -> Void)?) {
    let resolved = truncated(proposed, maxlength: maxlength)
    onChange?(resolved)
    binding?.wrappedValue = resolved
}
```

Keep a local `@State` value when `binding == nil`; when a binding exists, external changes are normalized in `onChange`/`onAppear` without recursively emitting a second user event.
